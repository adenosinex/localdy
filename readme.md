短视频浏览项目

本项目旨在实现一个类似于抖音的短视频浏览网页应用，用户可通过滑动屏幕切换视频，体验流畅的视频浏览与筛选功能。

## 功能模块
- 视频显示：默认筛选最新50个视频进行展示，支持分页浏览。
- 评价分数筛选：用户可对视频进行1-5分评价，并可按分数筛选视频。
- 视频标签（Tag）筛选：每个视频可设置多个标签，点击标签可快速筛选同类视频。
- 筛选词管理：所有筛选条件以标签形式显示在一行，支持点击小x号移除筛选条件。
- 视频详情：默认仅显示视频及文件名，点击“查看详情”可显示更多操作（如下载、分享、评论等）。
- 搜索功能：支持按关键词搜索视频。
- 响应式设计：适配手机、平板和PC端浏览体验。

## 使用技术
- 后端：Flask，负责视频数据管理、接口提供与用户鉴权。
- 前端：Vue 或其他灵活高效的前端框架，实现页面交互与数据展示。
- 数据库：可选用 SQLite 存储视频信息、标签、评价等数据。
- 视频存储：本地文件系统，文件夹时间段分类。

## 适用场景
- 个人离线短视频管理与浏览
 

## 快速开始
1. 克隆项目代码到本地
2. 安装依赖并启动后端服务
3. 启动前端项目，访问本地网页进行体验
